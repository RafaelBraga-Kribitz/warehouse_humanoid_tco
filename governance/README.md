# `governance/` — machine-readable audit state

This directory is the project's persistent, machine-checkable record of:

- **what is true** (`SSOT_REGISTRY.yaml` — canonical pointers for every fact),
- **what is open** (`findings/F-*.yaml` — one file per finding),
- **what is in flight** (`migrations/*.yaml` — multi-step refactors with completion criteria),
- **what is dying** (`DEPRECATIONS.yaml`, `ALLOWED_DEAD_CODE.yaml`),
- **what gates the code** (`WORKFLOW_REGISTRY.yaml` — every GHA workflow + its declared gates),
- **what the agent should do next** (`SESSION_HANDOUT.md`, generated by `make session-start`),
- **what the agent just did** (`SESSION_END.md`, written by `make session-end`),
- **the audit procedure itself** (`AUDIT_PROCEDURE.md` — Steward / Remediator / Adversary role contracts),
- **the auto-computed state** (`AUDIT_STATE.json` — machine-emitted; never hand-edited).

It exists because the prior operating model — narrative audits in dated markdown — could not survive `/clear`, ENOSPC, or context compaction. Each session re-derived findings, invented new scoring frameworks, and produced new artifacts that joined the pile without retiring the old. See `AUDIT_PROCEDURE.md` and `/root/.claude/plans/system-reminder-you-re-running-in-glistening-frog.md` for the full rationale.

## Lifecycle commands

```
make bootstrap      # install pre-commit hooks (one-time per clone)
make session-start  # read governance state → write SESSION_HANDOUT.md
make audit          # run all check_*.py + write AUDIT_STATE.json
make verify         # audit + tests + closed-finding re-verification
make session-end    # write SESSION_END.md and prompt for next-session priority
```

## File ownership

| File | Hand-edited? | Written by |
|---|---|---|
| `SSOT_REGISTRY.yaml` | yes | humans + agents |
| `AUDIT_PROCEDURE.md` | yes (rare) | humans |
| `findings/F-*.yaml` | yes | Remediator |
| `migrations/*.yaml` | yes | Remediator |
| `WORKFLOW_REGISTRY.yaml` | yes | humans + agents |
| `ALLOWED_DEAD_CODE.yaml` | yes | humans + agents |
| `DEPRECATIONS.yaml` | yes | humans + agents |
| `AUDIT_STATE.json` | **no** | `scripts/write_audit_state.py` |
| `CHANGELOG_GENERATED.md` | **no** | `scripts/generate_changelog.py` |
| `CODE_INVENTORY.yaml` | **no** | `scripts/generate_code_inventory.py` |
| `SESSION_HANDOUT.md` | **no** | `make session-start` |
| `SESSION_END.md` | partly | `make session-end` (prompts for next-priority free-text) |
